# Proyecto Final Backend

## Descripción
Proyecto final desarrollado en Node.js y Express para gestión de adopciones de mascotas.

Se realizaron:
- Tests automatizados
- Dockerización del proyecto
- Publicación de imagen en Docker Hub

## Instalación

npm install


## Ejecutar proyecto

npm start


## Ejecutar tests

npm test


## Docker

docker build -t adopme-backend .
docker run -p 8080:8080 adopme-backend
